## 1. 究極のC++自動化ディレクトリ構成

これまでの章の集大成として、読者の皆さんと一緒に作り上げてきたプロジェクトの最終形態を確認しましょう。以下のようなディレクトリ構成を持つのが、モダンなC++プロジェクトの理想的なテンプレートです。

```text
sonar_project/
├── CMakeLists.txt         # ビルド設定（CMake）
├── .github/workflows/     # CI/CD設定（GitHub Actions）
├── Dockerfile             # 開発環境の定義（コンテナ）
├── docker-compose.yml     # コンテナ一発起動スクリプト
├── include/               # C++ヘッダファイル
├── src/                   # C++プロダクトコード（コアロジック）
├── bindings/              # pybind11ラッパーコード
├── tests/
│   ├── cpp/               # GoogleTestコード（単体テスト）
│   └── python/            # pytest & NumPy数理評価コード
└── scripts/               # run_all_tests.sh等の一括実行スクリプト
```

このリポジトリを `git clone` し、`docker compose up -d` を叩くだけで、チーム全員が1秒で同じ開発・テスト環境を手に入れることができます。
