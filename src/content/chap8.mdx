## 1. 複数シナリオを回す Bash スクリプト

例えば、様々なカットオフ周波数やノイズレベルに対してテストを連続実行する `run_all_tests.sh` を作成します。

```bash
#!/bin/bash

# エラーが発生したら即座にスクリプトを停止するおまじない
set -e

echo "=== ソナー自動テストシステム一括実行 ==="

# テストしたいカットオフ周波数とノイズの配列
FREQUENCIES=(10.0 50.0 100.0)
NOISE_LEVELS=(0.1 0.5 1.0)

# 二重ループで総当たり（網羅）テストを実行
for freq in "${FREQUENCIES[@]}"; do
    for noise in "${NOISE_LEVELS[@]}"; do
        echo "実行中: 周波数=${freq}Hz, ノイズ=${noise}"
        
        # pytest にパラメータを引数として渡して実行
        # --junitxml でCI連携用のXMLレポートも出力
        pytest tests/test_sonar.py \
               --cutoff_freq=${freq} \
               --noise_level=${noise} \
               --junitxml=reports/result_${freq}_${noise}.xml
    done
done

echo "=== 全てのシナリオが正常に完了しました！ ==="
```

## 2. コマンド一発で全パターンを網羅

このスクリプトに実行権限を与え（`chmod +x run_all_tests.sh`）、ターミナルから叩くだけです。
