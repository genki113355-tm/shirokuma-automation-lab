## 1. テスト波形をPythonで合成する

ソナーや信号処理のテストでは、「特定の周波数の正弦波」に「ホワイトノイズ」を混ぜた擬似データがよく使われます。C++でこれをゼロから実装すると数十行かかり、バグの温床になりますが、Python（NumPy）なら数行で記述できます。

```python
# generate_data.py
import numpy as np

def generate_test_signal(duration=1.0, sampling_rate=1000):
    # 時間軸の生成（0秒〜1秒、1000サンプル）
    t = np.linspace(0, duration, int(duration * sampling_rate), endpoint=False)
    
    # 目的の信号（例: 50Hzの純粋なサイン波）
    target_signal = np.sin(2 * np.pi * 50 * t)
    
    # 海洋の環境ノイズ（ランダムなガウシアンノイズ）を生成
    noise = np.random.normal(0, 0.5, t.shape)
    
    # 信号にノイズを加算してテストデータ完成
    test_data = target_signal + noise
    
    return t, test_data
```

## 2. NumPy配列をそのままC++に流し込む（ゼロコピー）

先ほどの章でpybind11を導入した際、実は `#include <pybind11/numpy.h>` をインクルードしていました。
これにより、Python側の `numpy.ndarray`（配列）を、C++側でメモリのコピーを発生させずに直接ポインタとして受け取ることが可能です。

これを**ゼロコピー（Zero-copy）**と呼びます。

> 💡 **数GBのデータでも一瞬（ゼロコピーの威力）**  
> 数万〜数億サンプルの音響データやレーダーデータであっても、ゼロコピーならメモリの転送オーバーヘッドがゼロです。  
> Pythonの柔軟性とC++の暴力的な計算スピードを、一切のロスなく直結できるのがこのアーキテクチャの真骨頂です。
