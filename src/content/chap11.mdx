## 1. HIL（Hardware-in-the-Loop）とは？

ソフトウェアが正しく動いても、それが最終的に搭載されるハードウェア上で正しく動くとは限りません。HILは、実際のハードウェア（またはその一部）をテストループに組み込み、シミュレータから疑似的なセンサーデータを流し込んで動作を確認する手法です。

## 2. Pythonを「疑似センサー」として使う

Pythonのネットワーク機能（`socket` など）を活用し、Pythonスクリプトを「センサーハードウェア」に見立てて、UDP通信などでC++アプリケーションに波形データを送りつけるアーキテクチャを構築します。

```python
# pseudo_sensor.py (疑似センサー)
import socket
import time
from generate_data import generate_test_signal

UDP_IP = "127.0.0.1"
UDP_PORT = 5005

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
_, signal = generate_test_signal()

print("UDP送信開始...")
for data_point in signal:
    # データをバイナリ化して送信
    sock.sendto(data_point.tobytes(), (UDP_IP, UDP_PORT))
    time.sleep(0.001) # 1kHzのサンプリングレートを疑似再現
```

C++側では、UDPパケットを受信してリアルタイムにフィルタ処理を行うコードを実装します。
