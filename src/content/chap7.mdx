## 1. 期待値（正解データ）の用意

テストを自動化するには「正解」が必要です。今回はC++で実装したフィルタロジックの正解として、Pythonの科学計算ライブラリ `SciPy` のフィルタ関数が出力する結果を「理論値」として扱います。

## 2. pytestとMatplotlibによる全自動評価システム

Pythonのテストフレームワークである **pytest** を用いて、C++モジュールの出力を検証するテストコード（`test_sonar.py`）を記述します。

```python
# test_sonar.py
import numpy as np
import pytest
import matplotlib.pyplot as plt
from scipy.signal import butter, lfilter

# pybind11でビルドした自作C++モジュールを読み込み
import build.sonar_dsp as dsp  

def test_sonar_lowpass_filter():
    # 1. テストデータの生成（前章の関数を使用）
    t, input_data = generate_test_signal()

    # 2. C++（被試験対象）による高速な計算
    cpp_filter = dsp.SonarFilter(60.0)
    cpp_output = cpp_filter.process_array(input_data) # NumPy配列をゼロコピーで渡す

    # 3. Python(SciPy)による理論値の計算（正解データ）
    b, a = butter(4, 60.0 / (1000.0 / 2), btype='low')
    expected_output = lfilter(b, a, input_data)

    # 4. RMSE（二乗平均平方根誤差）の算出
    rmse = np.sqrt(np.mean((cpp_output - expected_output)**2))

    # 5. 許容誤差の判定と、失敗時のグラフ自動保存
    tolerance = 1e-3
    if rmse >= tolerance:
        # 誤差が大きい場合のみグラフを可視化して保存（デバッグ用）
        plt.figure(figsize=(10, 5))
        plt.plot(t, expected_output, label='Expected (SciPy)', linestyle='--')
        plt.plot(t, cpp_output, label='Actual (C++)', alpha=0.7)
        plt.title(f"Test Failed - RMSE: {rmse:.5f}")
        plt.legend()
        plt.savefig("error_report.png")
        plt.close()
        
        # テストを失敗させる
        pytest.fail(f"数理評価エラー: RMSE {rmse:.5f} が閾値 {tolerance} を超えました")
```

> 📌 **重要：エラー時のみ画像を生成する（CIを意識した設計）**  
> 毎回グラフを生成すると処理時間が延び、CIサーバーのストレージを圧迫します。  
> 上記のように「テストが失敗（許容誤差を超過）したときだけ画像を保存してレポートする」仕組みにしておくと、実務で非常に使い勝手の良い堅牢なシステムになります。
